# Magic Screen

A Cloudflare-first stock screener for Bursa Malaysia and US equities. The first release focuses on transparent data provenance, Magic Formula ranking, and conservative Shariah-status labelling.

## Status

Initial project scaffold. Live financial data requires a provider API key. No placeholder prices or fabricated fundamentals are presented as live data.

## Stack

- React + TypeScript + Vite
- Cloudflare Workers Static Assets
- Cloudflare D1
- Worker Cron Triggers

See `docs/SETUP.md` for deployment and provider configuration.
